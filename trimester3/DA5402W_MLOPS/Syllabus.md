# Syllabus of MLOps course

Source: page 11 of [Course Overview.pdf](lectures/lecture2_theory/Course%20Overview.pdf)

Modules

1. Introduction to MLOps
   - MLOps vs Traditional Software Development
   - Key Challenges in Production ML
   - MLOps Components, Workflows & Tooling Landscapes

2. Data Engineering
   - Data Pipelines (ETL, Batch & Streaming)
   - Tools: Apache Airflow, Kafka, Spark, Beam, Flume
   - Data Quality, Governance, Cleaning & Imbalance Handling

3. Model Development
   - ML Frameworks & Feature Engineering
   - MLFlow, Ray (Tracking & Distributed Training)
   - Streaming ML, MLib (Regression / Clustering)
   - Deep Learning, Transfer Learning, AutoML

4. Model Versioning & Collaboration
   - Git, GitHub / GitLab
   - Git LFS, DVC for data & model versioning

5. Deployment & Serving
   - Docker, Cloud, Serverless (AWS Lambda)
   - Tensorflow serving, FastAPI
   - Edge / On-prem deployment, Tensor-RT optimization

6. Monitoring & Optimization
   - Model Monitoring & Drift Detection
   - Logging (Kibana), Metrics (Promestheus)
   - Scaling & Performance optimization

7. CI/CD and Governance
   - CI/CD pipelines (Jenkins, GitLab CI/CD, Cloud tools)
   - TFX pipelines
   - Security, Explainability & Responsible AI
